CIFcurator

New curation

Searched in the descriptions of the PDB sequences (plain text, not case sensitive). Every structure with a chain whose sequence matches one of the hits is downloaded.

Also downloads the computed models that RCSB PDB finds for the keyword (full text search), next to the experimental structures.

A computed model has one protein chain only: no nucleic acids, ligands, waters or other copies of the protein (e.g. a homodimer is modelled as a monomer). It covers the full UniProt sequence, signal peptides included, and its B-factor column holds pLDDT.

Best matches first. Leave blank to download all of them.

Advanced Options

Residue columns present in at most this percentage of the structures are numbered with letters (insertion codes). Default 80.

One entity per line, ENTITY NAME:chainID,chainID,... (one chain ID per copy), e.g. TRIOSEPHOSPHATE ISOMERASE:A,Ab. Without it, the chains are named from the MMseqs2 clusters, and the generated input_file.txt is in the zip file: download it, edit it and upload it here to change the names.

A JSON file {"chain ID": "sequence", ...}, like the StandardSequences.json written by Step 4 (in standard_ChainID_bank/ of the zip file). Without it, the Standard Sequences are the consensus of all the structures.

Downloaded structures that should not be curated. Type them in the box and/or upload a text file: one or more per line, separated by spaces or commas (# starts a comment). Give a file name of clean_bank/ (pdb_00001abc+01.cif, with or without .cif), or a PDB ID (1abc) or entry (pdb_00001abc, AF-P00780-F1) to leave out all its assemblies. They stay in clean_bank/, and excluded_structures.txt in the zip file lists what was left out and the names that matched nothing. Without a list, all the structures are curated.
